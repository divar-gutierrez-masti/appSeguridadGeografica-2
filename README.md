# Seguridad Geográfica UPDS Sede Oruro

Aplicación móvil Android enfocada en proteger y habilitar información sensible según la ubicación geográfica del usuario, tomando como caso práctico **UPDS Sede Oruro**.

## ¿Qué resuelve?
Ayuda a que la información confidencial o de acceso restringido solo sea consultable dentro de una zona autorizada (geocerca), reduciendo riesgos de exposición o uso indebido fuera del área definida.

## Funcionamiento principal
- **Control por zona geográfica:** Detecta si el dispositivo se encuentra dentro o fuera del perímetro establecido para UPDS Sede Oruro.
- **Protección de datos:** Mantiene la información resguardada y accesible únicamente cuando se cumplen las condiciones de ubicación autorizada.

## Tecnologías utilizadas
- **Android Studio** (Kotlin / Java para Android)
- Servicios de ubicación / Geocercas (*Geofencing*)
- Cifrado de datos (AES)

## Contexto del proyecto
Desarrollado inicialmente como trabajo de posgrado/tesis aplicada y adaptado como prototipo funcional para **Abstracthon 2026** en Oruro.
